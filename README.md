
# Retail Sales Dashboard

This Power BI project delivers an interactive dashboard for a retail firm using five datasets, with a strong focus on sales trends and regional performance insights.

### 🔍 Key Highlights:
- Built a clean, minimal dashboard design for clear data storytelling
- Loaded and modeled 5 datasets with proper relationships
- Performed data cleaning in Power Query: missing value treatment, formatting, and filtering
- Sliced data by City Tier and performance metrics
- Created measures for Net Units, Sales Trend, and Weekday vs Weekend sales

📊 **Tool:** Power BI Desktop  
📁 **File:** Retail_Sales_Dashboard.pbix, datasets used, and dashboard-screenshot
